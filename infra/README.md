# Infraestructura / entorno

**Para esta 1ra entrega parcial** no se emplean contenedores, en cambio se usa un entorno validado:  PySpark 3.5.3 en `local[*]`.


**Tal como se sugirió en las primeras clases, para entregas futuras:** `docker-compose.yml` con una imagen Jupyter + PySpark para fijar
versiones (Java, Spark, Python) y que el Quickstart funcione igual en cualquier máquina.
AstraDB es un servicio gestionado, así que no se contenerizaría Cassandra.
